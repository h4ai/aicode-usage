# 模板搜索发现

## 1. 需求背景
- 目标：提供给开发者一种快速定位需要团队、特定语言、甚至包含指定 AI 规则支持的项目骨架的方案。
- 成功标准：用户能够通过 Web 或 CLI 输入关键词（如 `java springboot`）并附加过滤条件（如 `--tag backend --ai claude`）找到相应的模板。
- 范围边界：复用 Skill 系统的检索引擎进行匹配与分类，不包含模板内部每一行代码的深度搜索。

## 2. 需求描述
- 功能概述：一个供开发者查找“项目初始化模板”的搜索发现功能。支持基于热门（weeklyDownloads）、最新（createdAt）、名称（name）的排序。
- 业务价值：打破部门间信息孤岛，推行更高效、更合规的代码起点。让好用的模板通过排行被更多项目采用，减少团队重新“造轮子”。
- 核心场景：需要创建新微服务的研发，在 Web 端或 CLI 的搜索结果中，查看各部门公开的高质量 `@namespace/template`，比对后选择其中一个作为起点。

## 3. 用户旅程
- 主要用户：准备启动新项目的一线开发人员、架构师
- 主路径：
  1. 用户在 Web 端进入“模板” Tab（与 “Skills” 并列）或在终端输入 `skillhub template search <query>`。
  2. 输入搜索关键词，并可能选择 `--namespace`、`--tag`、`--ai`。
  3. 系统将查询提交，并附带排序参数（如默认 `popular`）。
  4. 搜索结果返回一组卡片或命令行表格展示，包含：名称、版本、描述、下载量。
  5. 用户点击感兴趣的模板进入详情，或通过命令行直接获取模板标识以用于 `init`。
- 异常路径：
  1. 无匹配结果 → 提示“未找到符合条件的模板”，并建议换个关键词或取消部分过滤条件。
  2. 查询超时/服务异常 → 提示“搜索服务暂时不可用，请稍后重试”。
  3. 不合法的过滤参数（如不存在的 namespace） → 提示“过滤条件不合法”，并返回全部或空列表。

## 4. 页面结构
- 页面布局：顶部搜索栏与筛选区，中间网格卡片列表，右侧排行榜（Top Templates）
- 关键区域：
  - 搜索/筛选栏：文本输入框、多选标签过滤（分类、支持的 AI 工具等）、Namespace 选择器、排序下拉菜单。
  - 搜索结果列表区：以卡片形式展示每个模板的关键信息。
  - 右侧/侧边热门排行区：显示过去一周下载量最高的模板。
- 状态流转：输入中 -> 检索中 -> 结果展示 / 无结果提示

## 5. 输入输出

### 5.1 输入
| 场景 | 输入 | 说明 |
|------|------|------|
| 关键词搜索 | 文本查询词 | 如 `"spring"` 或 `"react"` |
| 过滤条件 | 选择框 / CLI flag | 如 `?namespace=@frontend&tag=vue&ai=cursor` |
| 切换排序 | 排序下拉 / CLI arg | 选择 `popular`, `newest` 或 `name` |

### 5.2 输出
| 场景 | 输出 | 说明 |
|------|------|------|
| 返回结果集 | 模板卡片 / 列表 | 显示匹配的模板名称、简介、版本、当前热度及作者 |
| 推荐建议 | 空结果推荐 | 检索为空时提示其他热门标签或最近更新的模板 |
| CLI 表格 | 终端格式化输出 | CLI 端以表格对齐方式打印匹配结果 |
