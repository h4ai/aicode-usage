# Skill（技能）管理功能

## 1. 需求背景
- 目标：支持用户创建、编辑、管理和发现 Skill 资产，包括配置可见性和分类。
- 成功标准：用户可以成功创建 Skill，配置可见性，并且系统能够正确隔离不同权限的用户访问。
- 范围边界：包括 Skill 的基础元数据管理、可见性控制、状态流转和下载统计展示。

## 2. 需求描述
- 功能概述：用户在系统中创建新的 Skill 条目，填写名称、摘要、分类、标签，并设定访问范围。
- 业务价值：作为系统的核心资产，结构化的 Skill 管理有助于知识沉淀、分类查找和权限控制。
- 核心场景：发布者创建新 Skill，设置其仅对特定部门可见，或公开给全公司。

## 3. 用户旅程
- 主要用户：发布者（Publisher）及以上角色，普通浏览用户（User）。
- 主路径（创建）：
  1. 发布者点击"创建 Skill"按钮
  2. 填写全局唯一的 Slug（标识符）、名称、简介、分类（11 种可选）
  3. 选择可见性（公开 / 指定部门 / 仅自己）
  4. 添加相关标签
  5. 提交保存，系统生成草稿状态的 Skill
- 主路径（浏览）：
  1. 用户访问 Skill 市场大厅
  2. 浏览热门/最新 Skill 列表
  3. 系统自动根据用户所在部门过滤掉不可见的 Skill
  4. 点击进入详情页查看简介、作者、下载次数
- 主路径：
  1. 待补充
- 异常路径：
  1. Slug 格式不合法或已存在 → 提示修改
  2. 越权访问（非作者编辑或查看隐藏 Skill） → 提示无权限 (403/404)
  3. 部门设置错误导致自己不可见 → 系统保证作者始终可见

## 4. 页面结构
- 页面布局：
  - 我的发布页 (My Skills)：列表展示用户自己创建的 Skill
  - 创建/编辑表单页：包含各元数据字段的输入
- 关键区域：
  - 基础信息区（Slug、名称、分类下拉框、摘要）
  - 可见性设置区（单选框 + 部门多选下拉框）
  - 标签输入区
  - 保存/更新按钮
- 状态流转：草稿 (ACTIVE) → 隐藏 (HIDDEN) → 删除 (REMOVED)

## 5. 输入输出

### 5.1 输入
| 场景 | 输入 | 说明 |
|------|------|------|
| 填写 Slug | 字母、数字、连字符 | 3-64字符，全局唯一标识 |
| 填写基本信息 | 文本 | Skill名称和简介说明 |
| 选择分类 | 下拉选择 | 从预设的11个分类中单选 |
| 设置可见性 | 单选 + 多选 | 公开/部门/私有；选部门时需指定部门列表 |
| 添加标签 | 文本标签 | 方便后续搜索的关键词 |

### 5.2 输出
| 场景 | 输出 | 说明 |
|------|------|------|
| 保存成功 | 页面跳转 | 跳转到该 Skill 的详情/版本管理页 |
| 列表展示 | 过滤后的列表 | 用户只能看到自己有权访问的 Skill |
| 下载统计 | 数字展示 | 在卡片和详情页显示总下载数、本周下载数 |
| 校验失败 | 错误提示 | 提示 Slug 冲突或格式错误 |
