# Web UI：市场大厅与搜索功能

## 1. 需求背景
- 目标：提供一个易用的前端界面，让用户能够浏览、筛选和搜索系统中的所有可用 Skill 和项目模板。
- 成功标准：用户能够直观地看到热门推荐，通过多维度筛选找到目标资产，并能顺畅使用语义搜索。
- 范围边界：首页市场大厅布局、卡片展示、分类侧边栏、全局搜索框及其结果展示。

## 2. 需求描述
- 功能概述：构建系统的门户页面。分为"技能市场"和"模板市场"两个主要视图。提供按分类、最新、热门排序的卡片列表，以及顶部全局的智能语义搜索栏。
- 业务价值：作为用户触达系统资产的第一入口，优秀的展示和搜索体验直接决定了内部工具的复用率。
- 核心场景：用户进入系统，左侧点击"数据处理"分类，主区域自动刷新显示该分类下的热门工具；或者直接在顶部搜索栏输入"财务报表分析"，下拉框实时展示匹配结果。

## 3. 用户旅程
- 主要用户：所有企业员工
- 主路径（浏览）：
  1. 用户登录后默认进入市场首页
  2. 页面默认展示"最热"排序的 Skill 卡片网格
  3. 用户点击左侧的 "DevOps" 分类标签
  4. 列表无刷新更新为 DevOps 相关的工具
  5. 点击卡片进入详情页
- 主路径（搜索）：
  1. 用户在顶部导航栏的搜索框（OmniSearchBar）中输入内容
  2. 停止输入 300ms 后，搜索框下方浮出联想结果（展示匹配度和简介）
  3. 回车或点击"查看全部"，进入独立的搜索结果页
- 主路径：
  1. 待补充
- 异常路径：
  1. 对应分类下无数据 → 展示空状态插画"暂无相关内容"
  2. 网络请求失败 → 页面展示"加载失败，点击重试"按钮

## 4. 页面结构
- 页面布局：顶部导航栏（包含 Logo、搜索框、用户菜单） + 左侧边栏（分类/标签） + 右侧主内容区（卡片网格）
- 关键区域：
  - 顶部导航：OmniSearchBar（带加载动画和下拉面板）
  - 左侧边栏：11 个预设分类的切换列表，以及"技能/模板"大类切换
  - 内容区：控制栏（排序下拉框：热门/最新/名称），分页或加载更多控件
  - SkillCard：包含名称、分类标签、作者、下载次数、以及"部门专属"或"官方"徽章
- 状态流转：首页加载中（骨架屏） → 渲染完成 → 筛选/搜索触发 loading → 结果更新

## 5. 输入输出

### 5.1 输入
| 场景 | 输入 | 说明 |
|------|------|------|
| 分类点击 | 鼠标点击 | 选择左侧的分类或大类 |
| 排序切换 | 鼠标点击 | 切换热门/最新排序 |
| 全局搜索 | 文本输入 | 键入自然语言查询条件 |

### 5.2 输出
| 场景 | 输出 | 说明 |
|------|------|------|
| 列表渲染 | 资产卡片 | 动态刷新的网格列表 |
| 搜索下拉 | 浮层卡片 | 包含相似度百分比的快速预览列表 |
| 详情跳转 | 页面路由 | 点击卡片跳转至具体的 `/skills/slug` 页面 |
