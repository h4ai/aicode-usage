# 用户登录功能

## 1. 需求背景
- 目标：支持用户通过企业AD（Active Directory）账号登录系统，复用企业统一身份认证体系
- 成功标准：用户能够使用有效的AD域账号和密码完成登录，角色自动分配准确
- 范围边界：仅支持LDAP/LDAPS登录，系统不提供独立的账号注册功能

## 2. 需求描述
- 功能概述：系统对接企业AD，用户使用统一账号密码登录。登录成功后，系统自动同步用户信息，并根据AD组映射分配对应的系统角色（USER/PUBLISHER/REVIEWER/MODERATOR/ADMIN）
- 业务价值：复用企业统一身份体系，降低账号管理成本，确保内网身份安全，实现基于部门的自动权限隔离
- 核心场景：员工访问SkillHub系统，输入企业域账号及密码登录，进入相应权限的视图

## 3. 用户旅程
- 主要用户：企业内部员工（包括普通用户、发布者、审核员、管理员）
- 主路径：
  1. 用户访问受保护的页面或主动点击登录
  2. 重定向到统一登录页
  3. 输入AD账号（域账号）和密码
  4. 点击"登录"按钮
  5. 系统向AD域控发起验证，并同步用户属性（姓名、邮箱、部门、头像等）
  6. 登录成功，分配角色，跳转至目标页面或首页
- 异常路径：
  1. 账号或密码错误 → 提示"用户名或密码错误"，允许重试
  2. 账号已被禁用 → 提示账号异常，拒绝登录
  3. 连续登录失败超10次/分钟 → 触发防暴力破解限流，提示"请求过于频繁"
  4. AD域控服务不可用 → 提示"域控暂不可用，请稍后重试"（已登录用户不受影响）

## 4. 页面结构
- 页面布局：简洁的居中登录面板（Login Page），无注册/忘记密码入口
- 关键区域：
  - 系统Logo和名称栏
  - 用户名（域账号）输入框
  - 密码输入框
  - 登录按钮
  - 右上角用户菜单（登录成功后）：显示姓名、部门，包含"退出登录"操作
- 状态流转：未登录 → 输入账密 → 验证中 → 登录成功/失败

## 5. 输入输出

### 5.1 输入
| 场景 | 输入 | 说明 |
|------|------|------|
| 输入账号 | AD域账号 | 员工日常登录电脑/邮箱的账号 |
| 输入密码 | 域密码 | 对应的账号密码 |
| 点击登录 | 点击事件 | 触发登录验证流程 |
| 退出登录 | 点击事件 | 用户在右上角菜单点击退出 |

### 5.2 输出
| 场景 | 输出 | 说明 |
|------|------|------|
| 登录成功 | 页面跳转 | 获取用户完整信息及部门，跳转回首页或原访问页 |
| 认证失败 | 错误提示 | 统一显示"用户名或密码错误"，不区分具体原因 |
| 访问限流 | 拦截提示 | 1分钟内失败10次触发限制，需稍后重试 |
| 系统异常 | 错误提示 | AD连通性异常时的降级提示 |
