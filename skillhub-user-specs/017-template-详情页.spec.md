# 模板详情页

## 1. 需求背景
- 目标：提供给开发者一种全面了解某个特定“项目初始化模板”信息的方式，帮助其决定是否在项目中使用它。
- 成功标准：用户能够通过 Web 界面清晰地查看模板的基础信息（名称、命名空间、描述等）、README 文件渲染、版本历史、依赖 Skill 列表及如何进行 CLI 安装的说明；并提供 Web 的直接下载途径。
- 范围边界：包含对当前版本详细展示以及对历史版本的查看；不包含提供在线编辑其脚手架内容或直接在线运行测试代码的功能。

## 2. 需求描述
- 功能概述：一个全面展示某一个“项目初始化模板”详情的 Web 页面。模板被组织在类似 npm 的 `@team/template-name` 命名空间下。
- 业务价值：为模板提供门面，增强团队内部共享与技术沉淀。直观的“一键复制安装命令”功能减少了沟通和启动成本。
- 核心场景：开发人员浏览了搜索页面后，点击进入某个感兴趣的模板页面，了解它是基于哪些 AI 规则（如 `.claude/`）构建的，具体引入了哪些 `Skill`，阅读如何使用的指南，并最终点击复制 CLI 命令进行初始化。

## 3. 用户旅程
- 主要用户：所有有权访问该命名空间模板的开发人员
- 主路径：
  1. 用户在 Web 端模板列表页或通过 URL 链接访问特定模板详情。
  2. 页面加载模板的基本信息（如 `@backend-team/java-springboot`、当前最新版本号、上传者）。
  3. 用户浏览 `README.md` 内容渲染出的图文介绍和使用指南。
  4. 用户在右侧边栏查看该版本所依赖的 Skill 列表及其版本。
  5. 用户一键复制初始化命令：`skillhub init --template @backend-team/java-springboot --ai claude`。
  6. （可选）用户点击“版本历史”Tab，查看过去的版本更新记录和 Changelog。
- 异常路径：
  1. 模板不存在或被删除 → 提示“404 Not Found 模板不存在”。
  2. 用户无权限访问该命名空间下的私有模板 → 提示“403 Forbidden 权限不足”。
  3. README 文件获取失败或为空 → 展示“暂无描述”的空白提示。
  4. 模板处于非 PUBLISHED 状态（除非作者自己查看） → 普通用户无法访问，提示“模板审核中或未发布”。

## 4. 页面结构
- 页面布局：典型的详情页结构。左侧（或主体）展示文档和主体内容，右侧展示元数据、操作按钮及依赖信息。
- 关键区域：
  - 顶部/Header 区：模板名称、标签（Tags）、版本号、发布时间、作者。
  - 左侧/主体区（Tab 切换）：
    - README 渲染区（Markdown 展示区）。
    - 版本历史（Versions）列表。
  - 右侧边栏区：
    - 安装命令展示与一键复制按钮（`skillhub init...`）。
    - 直接下载 ZIP 的按钮。
    - 依赖项列表（Required Skills），链接至相应的 Skill 详情页。
    - 统计数据（最近 30 天下载量/总下载量等）。
- 状态流转：页面加载中 -> 渲染完成（如果是不可见状态则跳转至错误提示）

## 5. 输入输出

### 5.1 输入
| 场景 | 输入 | 说明 |
|------|------|------|
| 访问页面 | URL 路径/路由参数 | 如 `/templates/@backend-team/java-springboot` |
| 切换版本 | 下拉选择/点击特定版本 | 用户选择查看历史版本的详细信息与依赖项 |
| 一键复制 | 点击按钮操作 | 将初始化 CLI 命令复制到剪贴板 |
| 下载操作 | 点击下载 ZIP | 获取实体脚手架包 |

### 5.2 输出
| 场景 | 输出 | 说明 |
|------|------|------|
| 页面渲染 | Markdown 渲染与依赖列表 | 完整展示从远端拉取到的 `manifest` 和 README 内容 |
| 错误反馈 | 403 / 404 页面 | 根据访问权限与模板存在状态显示相应的警告页面 |
| 版本切换结果 | 对应的版本信息变更 | README, 初始化命令中携带 `@version` 参数，以及相应的依赖列表更新 |
