### 关键教训记录
- **Sub-agent workspace 隔离**：各 Agent 默认写到自己的 workspace（workspace-po/workspace-dev），跨 agent 文件需手动 `cp` 到 workspace-pm
- **Spec vs TECH-DESIGN 一致性**：PO 写 Spec 时没有严格照抄 TECH-DESIGN 模型，导致 Dev Review 发现 10 个 Blocker。**必须在任务指令中明确"以 TECH-DESIGN.md 为唯一权威来源，Prisma Schema 100% 一致"**
- **PO Agent token 耗尽**：大量修改任务可能超过 token 上限导致无输出，需拆分任务或 PM 自己接手
- **Dev Review 第一次超时**：300s 不够读 7 个大文件 + 写报告，增加到 600s 后成功。spawn subagent 时 runTimeoutSeconds 应根据任务复杂度设置
- **并行 Review 高效**：Dev 和 PO 同时 spawn 做复查，两个都在 2 分钟内完成，比串行快一倍
