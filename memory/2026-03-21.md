### 关键 Bug 修复：@Public 路由下 JWT 可选解析
- **问题**：`@Public()` 装饰器让 `JwtAuthGuard.canActivate` 直接 return true，跳过 JWT 解析 → `req.user` 永远 undefined → 部门可见性对所有人返回 403
- **根因**：即使带了有效 Bearer token，Public 路由也不解析 JWT
- **修复**：改造 `canActivate`，isPublic 时尝试解析 JWT（catch 错误不抛出），Observable 返回值用 `firstValueFrom` 转换
- **TS 编译问题**：`super.canActivate()` 返回 `boolean | Promise<boolean> | Observable<boolean>`，需要用 `isObservable()` + `firstValueFrom()` 处理
- **Commit**: `b2db472` (fix: parse JWT on @Public routes for optional auth)
- 文件：`packages/backend/src/auth/guards/jwt-auth.guard.ts`（新增 import `firstValueFrom, isObservable` from rxjs）
