**第二轮失败（22:30 报"Extra data: line 177"）**
- 根因：`$(command || echo 'fallback')` — patrol.js exit 1 时，bash `||` 把 fallback JSON 追加到正常 JSON 输出后面，变成两个 JSON 拼接
- 修复：改为 `$(command) || true` + 空输出检查

- **彻底修复**：提取独立 Python 文件 `parse-patrol.py`，cron 脚本只做 `echo | python3 parse-patrol.py patrol`
- 新文件：`/home/azureuser/.openclaw/workspace-pm/scripts/parse-patrol.py`
