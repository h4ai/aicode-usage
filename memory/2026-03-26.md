### 发现的问题
1. **OPS 收不到消息**: OPS binding 只监听 `accountId: "ops"` 的飞书应用，但这个群的 bot 是 `default` 应用。PM 发的消息走 default bot，OPS 收不到。
2. **PM 发的 @ 不变蓝**: `message` tool 以 bot 身份发消息，`@OpsClaw` 只是纯文本，不会变蓝，不会触发 OPS。
3. **OPS heartbeat 也被改成 0m**: OPS 之前把所有 Agent heartbeat 都改成 `"0m"`，不只是 PM 和 Monitor。Dev/QA/PO/SA 也被禁了。

### 解决方案 — 方案四（OPS 提出，沈老板批准）
在 `openclaw.json` bindings 里加一条：OPS 也监听这个群的 `default` 账号消息。OPS 已加并重启 Gateway。

### 飞书 @ mention 技术要点（重要！记住！）
**让 @ 变蓝的三要素：**
1. 用 `feishu_im_user_message`（用户身份发送）
2. `msg_type: post`（富文本格式）
3. at 标签带 open_id: `{"tag":"at","user_id":"ou_xxx","user_name":"OpsClaw"}`

**不能变蓝的方式：**
- `message` tool（bot 身份）→ 纯文本 @，不变蓝
- `feishu_im_user_message` + `msg_type: text` → 纯文本 @，不变蓝

- ✅ 以沈老板身份发的消息 OPS 能收到
- ⚠️ 以 bot 身份发的消息 OPS 可能收不到（取决于方案四 binding 是否生效）
