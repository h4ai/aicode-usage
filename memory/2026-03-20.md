## Docker Backend Dockerfile 最终解决方案 (18:05-18:20)

### pnpm monorepo Docker 构建问题 — 8 轮迭代总结
- **根因**：pnpm 的 `node_modules` 使用 symlink + `.pnpm` store 结构，Docker COPY 不保留 symlink 指向
- **失败方案**：
  1. `cp -rL root/node_modules` → 缺少 `@nestjs/core`
  2. `cp -rL packages/backend/node_modules` → 有 `@nestjs/core` 但缺 `tslib`（transitive deps 缺失）
  3. `pnpm deploy --legacy --prod` → 只有 23 个顶层包，`tslib` 缺失
  4. `pnpm deploy --legacy`（不加 --prod）→ 34 个包，仍缺 `tslib`
  5. `npm install` 直接用 backend/package.json → `workspace:*` 协议不兼容
- **最终成功方案（npm-only）**：
  1. COPY backend `package.json`
  2. `sed` 替换 `"@skillhub/shared": "workspace:*"` → `"file:../shared"`
  3. COPY `packages/shared/` 到 `./shared/`
  4. `npm install --legacy-peer-deps` → 所有依赖扁平安装
  5. `npx nest build` → 构建成功
  6. `npm prune --omit=dev` → 精简生产依赖
  7. 验证 `@nestjs/core` ✅ + `tslib` ✅ + `dist/main.js` ✅
