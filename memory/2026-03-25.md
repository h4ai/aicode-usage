## 文件 Inbox 设计要点

```
PM 写 dispatch 文件 → Agent workspace/inbox/TASK-XXX.dispatch.json
Agent heartbeat 扫描 → 读取 → 执行 → 写 .done.json 或 .failed.json
```

- 设计文档: `workspace-pm/docs/file-inbox-design.md`
- dispatch 格式: `_schema: file-inbox-dispatch-v1`, 包含 taskId/dispatchedAt/targetAgent/taskFile/summary/priority/status
- 状态流转: pending → processing → done/failed
